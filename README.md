# Gimhani Dilmika — Software & AI Portfolio

A modern React + Vite portfolio for **Gimhani Dilmika**, a Computer Engineering undergraduate focused on Software Engineering, Full-Stack Development, and AI/ML.

The portfolio keeps the clean, animated presentation style of the supplied reference while using a different visual identity, colour palette, content structure, and project presentation.

## Highlights

- Responsive React + Vite portfolio
- Dark / light theme
- Animated hero section with floating technology chips
- About, skills, projects, research, and contact sections
- Project category filtering
- GitHub links for the supplied repositories
- LinkedIn and email contact links
- Framer Motion animations
- Mobile-friendly navigation
- Research showcase

## Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## 2026 Neon Portfolio Redesign

This version includes the responsive neon/cyan/purple landing page, real uploaded portrait, animated 3D-style portrait orbit, skill bubbles, highlight cards, improved mobile navigation, preserved About / Skills / Projects / Research / Contact sections, and dark/light mode. All application content and links remain editable in `src/data.js`.

**Important:** `public/Gimhani-Dilmika-CV.pdf` is an automatically prepared portfolio-summary placeholder, not an official CV. Replace it with your real CV before publishing or using the Download CV button in applications.

Commands: `npm install`, `npm run dev`, `npm run build`. Publish the `dist` folder to GitHub Pages. For the `GimhaniDilmika.github.io` repository, the default root base path works.
