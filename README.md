# Gimhani Dilmika — Software & AI Portfolio

A modern React + Vite portfolio for **Gimhani Dilmika**, a Computer Engineering undergraduate focused on Software Engineering, Full-Stack Development, and AI/ML.

The portfolio keeps the clean, animated presentation style of the supplied reference while using a different visual identity, colour palette, content structure, and project presentation.

## Highlights

- Responsive React + Vite portfolio
- Dark / light theme
- Animated hero section with floating technology chips
- About, skills, projects, research, and contact sections
- Project category filtering
- GitHub links for the supplied repositories
- LinkedIn and email contact links
- Framer Motion animations
- Mobile-friendly navigation
- Research showcase

## Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
